RER B : tableau de rendu des états

Données inventées. Un train par état, sur une voie droite fictive. Aucune donnée PRIM, aucun appel réseau, aucun fond de carte. Les rendus « existe déjà » reprennent le code de la carte ; les rendus « proposé » sont des idées à juger.
Caméra :
Souris : glisser = déplacer ; Ctrl + glisser, clic droit + glisser ou Maj + glisser = pivoter et incliner ; molette = zoom (le modèle détaillé apparaît dès le zoom 15). Colonne de gauche : thème clair ; colonne de droite : thème sombre. Lignes : de près (zoom de départ 16,1, détaillé à taille réelle) ; distance moyenne (15,2, détaillé élargi) ; de loin (13,6, icône : le détaillé ne s'affiche qu'à partir du zoom 15).
